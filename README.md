
Network issue - Troubleshooting
## Issue
User reported that the system was unable to access the internet.

## Environment
- OS: macOS
- Network: Wi-Fi

## Symptoms
- No internet access
- Websites not loading
- Ping requests failing

## Troubleshooting Steps
1. Checked Wi-Fi connection status
2. Verified IP address using `ifconfig`
3. Tested connectivity using `ping google.com`
4. Identified network disconnection / DNS issue
5. Reconnected Wi-Fi / corrected DNS settings

## Commands Used
ifconfig

ping google.com

## Open Terminal and run
ping google.com

ping ipconfig ip address
